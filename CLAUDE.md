## 📋 Project Overview

SocialPeak is a professional, fully responsive landing page for a social media marketing agency. It showcases services, case studies, ROI calculator, pricing plans, and FAQs with interactive features and modern design.

**Tech Stack:**
- HTML5 (semantic structure)
- CSS3 (Grid, Flexbox, responsive design)
- Vanilla JavaScript (no frameworks)
- Unsplash CDN for images
- Font Awesome icons

**Key Features:**
- Responsive mobile-first design
- Interactive ROI calculator
- Smooth scrolling navigation
- FAQ accordion
- Case studies showcase
- Pricing comparison
- Call-to-action sections

## 📝 Customization Guide

Quick customization references from [`docs/README.md`](docs/README.md):

### Change Brand Name
- Update `.logo` in HTML
- Change footer sections
- Update `<title>` tag

### Modify Colors
- Edit CSS variables in `:root` selector
- All colors use variables for consistency

### Update Contact Information
- Edit footer contact details
- Modify phone, email, address

### Add Custom Images
- Replace Unsplash URLs (see [`docs/IMAGES_ALL_UNIQUE_FINAL.md`](docs/IMAGES_ALL_UNIQUE_FINAL.md))
- Maintain aspect ratios
- Optimize for web

### Modify Pricing Plans
- Edit `.pricing-card` content
- Update amounts and features
- Adjust tiers as needed
