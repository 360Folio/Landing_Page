## 📝 Customization Quick Guide

### Change Brand Name
```html
<!-- In index.html -->
<div class="logo">
    <i class="fas fa-chart-line"></i> YourBrandName
</div>
```

### Update Colors
```css
/* In styles.css :root */
--primary-color: #your-color;
--secondary-color: #your-color;
```

### Modify Pricing
```html
<!-- Update pricing tiers in pricing section -->
<span class="amount">1,500</span>
```

### Replace Images
```html
<!-- Update image URLs -->
<img src="your-image-url" alt="description">
```
